# Monitor formativo MDC · GitHub Pages

Versión estática del prototipo ilustrativo desarrollado por el **Dr. Ramsés Vázquez Lira**, Computational Psychometrics Lab, Facultad de Psicología, UNAM.

## Publicación

1. Suba todos los archivos de esta carpeta a la raíz de un repositorio de GitHub.
2. Abra **Settings → Pages**.
3. Seleccione **Deploy from a branch → main → /(root)**.

El archivo de entrada es `index.html`. No se requieren dependencias, compilación ni servidor.

## Alcance

Todos los datos son simulados. Esta versión no estima perfiles mediante modelos de diagnóstico cognitivo y no debe utilizarse para decisiones académicas reales.
